# Juegos de Mayra

Juego académico de exodoncia simple en español, adaptable a celular y computadora.

- Ingreso del nombre del estudiante.
- Tres misiones consecutivas: mesa quirúrgica, caso clínico y radiografías.
- Puntaje final como promedio de los porcentajes de las tres misiones.
- Radiografías e ilustraciones incorporadas en el HTML.

Para jugar en iPhone, abre la página web en Safari. La vista previa de un adjunto HTML puede no ejecutar las misiones.

El archivo `juego.html` también puede abrirse directamente en un navegador compatible sin conexión. La página de entrada es `index.html`.

Es una representación académica simplificada. Las claves radiográficas siguen la información docente aportada; no constituye una herramienta de diagnóstico.
